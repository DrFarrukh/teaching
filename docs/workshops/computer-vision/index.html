Run the lab

Open the notebook in Colab, select Runtime → Change runtime type → T4 GPU, and run the cells in order. If a GPU is unavailable, the notebook uses its smaller CPU configuration.

The notebook downloads its sample images, CIFAR-10 dataset and pretrained model weights automatically, so an internet connection is required. You do not need to download the repository or upload a separate image folder.

Use PowerPoint or Impress slideshow mode to play the animations in the slides.
