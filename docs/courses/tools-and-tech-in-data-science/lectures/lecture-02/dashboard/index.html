How this was calculated

Each concentration is truncated to one decimal, mapped through the specified breakpoint interval, and rounded to an integer using half-up rounding.

Seven-day means require seven observed daily values. Category counts use observed valid days. The notebook also compares January 1–February 28 across all four years.

Sources and limits

The local course files are AQI-Data-20-22.csv and AQI-Data-23.csv. Forty wholly blank records in the latter were removed with an audit record. Original PDF transcription and monitoring representativeness have not been independently established.
