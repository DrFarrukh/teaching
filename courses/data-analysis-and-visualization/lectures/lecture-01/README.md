# Lecture 1 · Data, evidence and market-share claims

Did Suzuki, Toyota and Honda lose dominance in the passenger-car sales recorded in the PAMA workbook? Population versus reporting frame, an analysis-ready record, recorded share and CR3, and a denominator sensitivity check.

The notebook is saved with its outputs, so you can read it without running anything.

## Run it yourself

- **Google Colab:** open the link above and run the notebook from the top; it downloads the prepared data files it needs.
- **Locally:** from this folder, `python -m pip install -r requirements.txt`, then start Jupyter here and open `notebook.ipynb`.

## Files

`data/` holds the prepared CSVs and `data_dictionary.md` their scope and limits. `prepare_data.py` rebuilds them from `pama_monthly_production_sales.xlsx`. [Web slides](https://drfarrukh.github.io/teaching/courses/data-analysis-and-visualization/lectures/lecture-01/slides/) are also available.
