# Lecture 3 · From totals to a defensible visual argument

What changed in recorded passenger-car sales from 2023–24 to 2024–25? Absolute change, contribution, relative growth, share change and an equal-growth benchmark; choosing a chart for the comparison; testing a changed baseline.

## Run it yourself

- **Google Colab:** open the link above and run the notebook from the top. The first code cell downloads this lecture's folder and installs the packages.
- **Locally:** from this folder, `python -m pip install -r requirements.txt`, then start Jupyter here and open `notebook.ipynb`.

## Files

`data/passenger_cars_long.csv` is the validated monthly table from Lecture 2; `data/model_lookup.csv` maps model groups to manufacturers. Figures are written to `outputs/`. Source context: [PAMA monthly production and sales](https://pama.org.pk/monthly-production-sales-of-vehicles/).
