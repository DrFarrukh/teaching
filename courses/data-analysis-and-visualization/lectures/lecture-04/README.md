# Lecture 4 · What does an average hide?

Two PSL 2017 teams share a death-over average. Distributions, ECDFs, quantiles and tail rates; how many independent observations there really are; bootstrap intervals; and what claim the evidence can defend.

## Run it yourself

- **Google Colab:** open the link above and run the notebook from the top. The first code cell downloads this lecture's folder and installs the packages.
- **Locally:** from this folder, `python -m pip install -r requirements.txt`, then start Jupyter here and open `notebook.ipynb`.

## Files

`data/` holds the prepared over-level and match tables derived from the [Cricsheet](https://cricsheet.org/downloads/) Pakistan Super League archive; preserve that attribution when sharing derived data or figures. Figures are written to `outputs/`.
