# SE-801 Lecture 6 Data Dictionary

This document details the synthetic datasets, tensor structures, and serialized files generated by the Lecture 6 code.

## 1. Concentric Multi-Ring Synthetic Dataset

- **Generated by:** `generate_ring_dataset()` in `lecture_06_experiments.py` (RUN 14).
- **Domain:** Continuous 2D plane $\mathbb{R}^2$.
- **Class 0 (Inner Ring):** Radius $r_0 = 0.8$, radial Gaussian jitter $\sigma = 0.09$.
- **Class 1 (Middle Ring):** Radius $r_1 = 1.8$, radial Gaussian jitter $\sigma = 0.09$.
- **Class 2 (Outer Ring):** Radius $r_2 = 2.8$, radial Gaussian jitter $\sigma = 0.09$.
- **Total instances:** 1,200 points (400 per class, balanced).
- **Tensor splits:**
  - `X_train`, `y_train`: Shape `[720, 2]`, `[720]`, `dtype=torch.float32`, `torch.int64`.
  - `X_val`, `y_val`: Shape `[240, 2]`, `[240]`, `dtype=torch.float32`, `torch.int64`.
  - `X_test`, `y_test`: Shape `[240, 2]`, `[240]`, `dtype=torch.float32`, `torch.int64`.

## 2. Experimental Output Artifacts

All artifacts are written to `outputs/` (or the directory indicated by `ANN_L6_OUTPUT_DIR`):

| File | Type | Description |
|---|---|---|
| `activation_derivatives.png` | PNG image | Side-by-side plots of Sigmoid, Tanh, and ReLU alongside their local derivatives $\phi'(z)$, demonstrating saturation limits. |
| `layer_activation_distributions.png` | PNG image | $4 \times 4$ histogram grid showing the variance and activation distribution across Layers 1, 3, 5, and 8 under 4 initialization schemes. |
| `initialization_comparison_curves.png` | PNG image | 3-panel plot showing training loss, validation accuracy, and First-Layer Gradient Norm ($\|\nabla_{W^{(1)}} L\|_2$) across 80 epochs. |
| `dropout_regularization_curves.png` | PNG image | Training and validation loss/accuracy curves comparing unregularized MLP against inverted dropout ($p=0.25$). |
| `layer_gradient_flow.png` | PNG image | Bar plot of gradient norms across layers `fc1` to `fc4` verifying healthy, non-vanishing gradient propagation. |
| `experiment_results.json` | JSON file | Machine-readable held-out test evaluation records containing test loss and test accuracy for each model configuration. |
