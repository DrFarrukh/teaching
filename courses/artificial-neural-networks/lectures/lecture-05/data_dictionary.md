# Lecture 5 Synthetic Data Dictionary

## Dataset definition

Every row is one independent draw of two unitless synthetic features and a binary mixture-component class. There are no people, sessions, timestamps or physical sensor measurements.

| Column | Type | Meaning |
|---|---|---|
| `feature_1` | Floating-point | First coordinate, Gaussian noise SD 0.35 around a chosen center |
| `feature_2` | Floating-point | Second coordinate, independent coordinate noise with SD 0.35 |
| `class` | Integer 0 or 1 | Class 0 for same-sign centers; class 1 for opposite-sign centers |

Centers are `(−1,−1)`, `(−1,1)`, `(1,−1)`, `(1,1)`. The label belongs to the generating component; it is not recomputed from the signs of a noisy point. Rare points can cross an axis because Gaussian noise has unbounded support.

## Splits and preprocessing

| Split | Generator seed | Rows per center | Total rows | Rows per class |
|---|---:|---:|---:|---:|
| Training | 501 | 60 | 240 | 120 |
| Validation | 502 | 20 | 80 | 40 |
| Test | 503 | 20 | 80 | 40 |

Each split uses its own random generator and is shuffled independently. Fit feature means and population-standard-deviation scales on training features only. Reuse those values for validation and test. Saved CSVs contain raw features; the notebook computes standardized tensors.

## Output files

- `train_synthetic.csv`, `validation_synthetic.csv`, `test_synthetic.csv`: raw synthetic splits. Test labels are present for reproducibility but are excluded from tuning and enter performance reporting only in RUN 21.
- `learning_curves.csv`: one row per model and epoch, with training/validation mean cross-entropy and accuracy. Models are `linear`, `affine stack`, and `ReLU MLP`.
- `experiment_results.json`: protocol, versions, checks, selected validation checkpoints, frozen test reports and initialization repeats.
- `chart_data.json`: exact points and curve values used by the native editable slide charts. Evaluated decision-grid points are predictions, not observed samples.
- `figures/`: scientific plots generated by the notebook for study and classroom demonstration. The deck uses native editable data charts rather than screenshots of these plots.

## Metric conventions

Cross-entropy is the natural-log loss averaged across examples. Accuracy is the fraction of correct argmax labels. Confusion matrices use true rows and predicted columns. Balanced accuracy is the mean of class recalls. The primary validation and test samples have equal class supports, so accuracy and balanced accuracy coincide for this run.

The intended generalization population is fresh draws from the same fixed mixture. A claim about people, instruments or temporal transfer needs corresponding data and a different split design.
